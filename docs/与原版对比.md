# 与原版 KiC-AI 的对比

| 能力 | 原版 | 本增强版 |
|---|---|---|
| LLM 后端 | 仅本地 Ollama（`localhost:11434`） | 云端 6 平台（DeepSeek/OpenAI/智谱/通义/MiniMax/自定义）+ Ollama 回退 |
| 界面语言 | 英文 | 中文为主，中英可切换，英文原文保留 |
| 语言列表 | 6 种（无中文） | 中文 + English |
| 联网搜索 | ❌ | ✅ DeepSeek 原生搜索，关键词自动触发 + 手动按钮 |
| 配置窗口 | 固定大小 | 可滚动（兼容 wxPython 4.2） |
| AI 之外 | Nexar 价格查询 | 保留 |

## 我们改动/新增的文件

- `plugins/ai_dialog.py` — 云端 API 请求逻辑、中文界面、联网搜索、`_t()` 双语切换、`on_lang_change`、滚动支持相关（主窗口）
- `plugins/config_manager.py` — LLM 配置项、联网搜索配置、`tr()` 双语切换、`wx.ScrolledWindow` 滚动
- `kicad-gateway.mjs` — 全新：Harness 会话 ⇄ MCP 服务器桥接（原创代码）
