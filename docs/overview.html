3三层安全防线（Qoder / CodeSec 风格）

L1

security-patterns.yaml（14 条规则：密钥/AWS/私钥/SQL注入/eval 等）→ 本机 pre-commit 钩子 + GitHub Actions CI（push/PR 自动）

L2
LLM 轻量审查 · diff
security-review.py --diff / --staged：DeepSeek 对未提交改动做"安全工程师"式审查
L3
LLM 深度审查 · commit 范围 / 全仓库
security-review.py --commits A..B / --all
实测：审查真实提交 → 6 条 LOW 建议 + "未发现明显安全问题" ✅
